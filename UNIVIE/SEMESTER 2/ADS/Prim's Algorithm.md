Find the [[MINIMUM SPANNING TREE]] in a weighted [[GRAPHS]].

## Complexity
$O (n^2)$ if an adjancency matrix is used.

## Algorithm

Create a list $Visited = \{\}$
Pick a node, add to visited
Choose smallest edge that connects to an unvisited edge.
